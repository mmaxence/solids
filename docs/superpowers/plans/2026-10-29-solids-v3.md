# solids v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship solids v3: effect intensity (`mix`), performance metrics, an agent-first landing with a reorganized page under the hero, and a universe scene with depth of field.

**Architecture:** Four streams on worktrees off `main`. M, P and G run in parallel; U starts after M merges. Each stream extends `scripts/check.mjs` and leaves `npm run check` green on its branch. Merge order M, P, G, U; the controller resolves `gen-site.mjs` and `check.mjs` overlaps.

**Tech Stack:** unchanged.

**Spec:** `docs/superpowers/specs/2026-10-29-solids-v3-design.md` (plus v1 and v2 specs next to it).

## Global Constraints

- Zero runtime dependencies. Budgets: core ≤ 18 KB, full ≤ 60 KB gzipped.
- Reduced motion, the 16-context cap, `dpr` cap honored. No em dashes anywhere.
- `npm run check` green per branch (run with the sandbox bypass locally). Commit per logical step, never push.

## Review Focus

1. `glow-mix="0"` on a scene renders byte-identical to no effect, including alpha at object edges. (M)
2. A universe with `count="0"` or a `shapes` list naming an unknown tag: no throw, zero or only-known children. (U)
3. Benchmark on a machine without the GPU timer extension: table still fills with CPU numbers, "GPU" column says unavailable. (P)
4. Landing at 500 px: the four-layer row, the catalogue grid and the universe band wrap without horizontal overflow; live minis stay under the 16-context cap (one scene per card is too many: use one scene per section). (G, U)
5. Universe `depth` or `focus` changed at runtime: defocus amounts update on existing children without regenerating positions. (U)
