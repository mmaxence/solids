# solids v8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Tap input and three tap rules, a field texture and non-square quads in the core, `<sd-text>` as the HTML-to-3D bridge, and a hero with the Solids wordmark and a presets-plus-Tweak dock.

**Spec:** `docs/superpowers/specs/2026-10-30-solids-v8-design.md`

## Global Constraints
Core under 18 KB with interactions stubbed; full under 60 KB; no em dashes; check page rules (no backticks, no `${`, `[0-9]`, no trailing `//` comments on code lines); square objects byte-identical.

## Review Focus
1. A scroll flick on a phone over the hero must never fire a shockwave (pointercancel, travel, time).
2. The wordmark on light must read without any effect; metal and cel on pixel letters.
3. The field texture and the effect passes share texture units: unit 1 for the field, unit 0 for `uScene`; a program with both must not confuse them.
4. `uBound` for a wide box: no clipped halo at the box ends; the far limit covers the long side.
5. Presets must leave Copy code truthful (the markup equals what the controls say).
