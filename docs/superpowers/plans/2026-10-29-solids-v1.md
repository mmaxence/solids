# solids v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `mmaxence/solids`: a zero-dependency WebGL2 web-component library of six SDF objects with animations, effects and a gravity interaction, plus a generated GitHub Pages site in the voice-ring register.

**Architecture:** `<sd-scene>` owns one canvas and a rAF loop; each `<sd-*>` child is an SDF fragment shader drawn on a quad sized to the child's layout rect × bleed. Animations and interactions are pure functions producing `{rotation, offset, scale, uniforms}`; effects are fullscreen passes over FBOs (per-object FBO when the object has effects, scene chain last). One Node script globs `src/objects/*/manifest.json` and the bundle's `meta` exports to generate the site.

**Tech Stack:** TypeScript, esbuild (dev only), WebGL2, Custom Elements + Shadow DOM, Node 22 stdlib for scripts, headless Chrome for checks, GitHub Actions + Pages.

**Spec:** `docs/superpowers/specs/2026-10-29-solids-design.md`

## Global Constraints

- Zero runtime dependencies. Dev deps: `typescript`, `esbuild` only.
- Budgets (gzipped): core ≤ 15 KB, full `dist/solids.js` ≤ 40 KB. One bundle, no lazy loading.
- Tag prefix `sd-`. Attributes kebab-case, mirrored as camelCase properties; attribute change re-renders without re-mount.
- Honor `prefers-reduced-motion`: animations freeze at rest pose; direct pointer input still responds.
- No WebGL2 → render nothing, keep the box, set `data-fallback` on the element.
- rAF loop pauses when scene is off-screen (IntersectionObserver) or `document.hidden`.
- Canvas transparent, DPR capped at 2, raymarch ≤ 64 steps, scene effects at half resolution.
- Eases: state and animation changes ~400 ms; nothing snaps when the gravity center changes.
- Site: static, generated by one Node script, dark default, light toggle, system fonts.
- MIT license. Commit `dist/` on main.
- Writing conventions (Max): no em-dashes in any copy, README or site text.

## Review Focus

1. Scene with zero children or an object with an unknown `animation`/`effect` name: must render (or render nothing) without throwing. Test in Task 2 and Task 3.
2. A `<sd-*>` added to or removed from a scene after first paint (dynamic DOM): registry updates, no stale draws. Test in Task 2.
3. Two objects both marked `gravity="center"`: first in DOM order wins, others treated as `orbit`; no NaN. Test in Task 6.
4. Scene resized to 0×0 (display:none parent) then shown again: no GL errors, FBOs re-sized. Test in Task 5.
5. WebGL context lost (`webglcontextlost` event): loop stops, `webglcontextrestored` rebuilds programs. Test in Task 7.

### Task 2: Core renderer, scene, base object, first object `orb`

**Files:**

**Interfaces:**
- `registry.ts`: `defineObject(manifest: Manifest, frag: string): void` registers a custom element `manifest.tag` extending `SdObject`. `type Manifest = { name: string; tag: string; description: string; bleed?: number; uniforms: UniformDef[]; tags?: string[] }`, `type UniformDef = { name: string; type: 'float'|'vec3'|'color'; default: number|number[]|string; min?: number; max?: number; step?: number; label: string }`. Also `animations: Map<string, Animation>`, `effects: Map<string, EffectDef>`, `interactions: Map<string, Interaction>` (types defined in Tasks 3, 5, 6; declare them here as `unknown`-free interfaces now).
- `object.ts`: `class SdObject extends HTMLElement` with `manifest`, `frag`, `rect: DOMRect` (layout, refreshed by scene), `state: number` (eased 0..1 from attribute `state`: idle 0.25, active 1, busy 0.6, off 0), `color: [r,g,b]`, `uniforms: Record<string, number|number[]>` built from manifest defaults + attributes, `anim: {rotation: Float32Array(9), offset:[x,y], scale:number, z:number}` written by animations/interactions each frame. `observedAttributes` = manifest uniform names (kebab) + `animation speed effect state color size gravity`. - `scene.ts`: `class SdScene extends HTMLElement`; shadow root holds `<canvas>` absolutely positioned over `:host{position:relative;display:block}`; `objects: Set<SdObject>` maintained from `slotchange`/MutationObserver on children (direct and nested); `tick(t)` draws each object sorted by `anim.z`. Attributes: `interaction`, `effect`, `theme`, `paused`, `gravity-strength`.
- `gl.ts`: `createGL(canvas): WebGL2RenderingContext | null`, `program(gl, vert, frag): WebGLProgram` with a cache keyed by source, `setUniforms(gl, prog, values)`, `drawQuad(gl)`. Core uniforms set every draw: `uTime, uResolution, uPointer, uRotation, uScale, uState, uTheme, uColor`.
- `orb/frag.glsl`: SDF sphere, fresnel rim, glassy highlight, `uColor` tint; manifest uniforms `glow` (0..1, 0.6), `rim` (0..2, 1.0). Exposes nothing else.
- `check.mjs` `manifests()`: every `src/objects/*/manifest.json` validates against the shape above (hand-rolled checks, no lib); every `frag.glsl` declares each manifest uniform. `shaders()` + `smoke()`: start `node:http` static server on a free port serving repo root; write `scripts/.check-page.html` that loads `dist/solids.js`, mounts one `<sd-scene>` with every registered object, then after two frames writes to `document.title` a JSON `{compileErrors:[...], nonZeroPixels:n, consoleErrors:[...]}` (pixels via `gl.readPixels` on the scene canvas, exposed as `scene.__readPixels()` only when `window.__SD_CHECK`); run Chrome `--headless=new --disable-gpu --use-angle=swiftshader --enable-unsafe-swiftshader --dump-dom URL`, parse `<title>`, assert no errors and `nonZeroPixels > 1000`. ### Task 3: Animations and state easing

**Files:**
- Create: `src/animations/{index.ts,idle.ts,spin.ts,pulse.ts,breathe.ts,float.ts}`
- Modify: `src/core/object.ts` (apply animations), `src/core/registry.ts` (type), `src/index.ts`

**Interfaces:**
- `type Animation = { meta: { name: string; description: string; params: UniformDef[] }; fn: (t: number, speed: number, o: SdObject) => Partial<{ rotation: [rx,ry,rz]; offset: [x,y]; scale: number; uniforms: Record<string, number> }> }`. `index.ts` exports `animations: Animation[]` and registers each into `registry.animations`.
- Object parses `animation="spin breathe"` into a list; each frame sums offsets, multiplies scales, composes rotations in order. `speed` attribute scales `t`. Changing the `animation` attribute cross-fades: previous result blended to new over 400 ms with `ease`. `state` attribute eases `o.state` toward its target with tau 150 ms. `prefers-reduced-motion`: `t` is frozen at 0 for animations.
- Definitions: `idle` (slow 6 s yaw sway ±8°), `spin` (continuous y rotation, 1 turn / 8 s at speed 1), `pulse` (scale 1 ± 0.06 at 1.2 Hz), `breathe` (scale 1 ± 0.03 and `uState` modulation ±0.1 at 0.25 Hz), `float` (offset y sin ±6 px at 0.4 Hz, slight x drift).

### Task 5: Effects pipeline and six effects

**Files:**

- Modify: `src/core/scene.ts`, `src/core/object.ts`, `src/core/registry.ts`, `src/index.ts`

**Interfaces:**
- `fbo.ts`: `createFBO(gl, w, h): FBO`, `resizeFBO(fbo, w, h)`, `type FBO = { fb: WebGLFramebuffer; tex: WebGLTexture; w: number; h: number }`. `PingPong` pair helper: `swap()`.
- `type EffectDef = { manifest: { name: string; description: string; params: UniformDef[] }; frag: string }`. Effect frag receives `uScene` (sampler2D), `uResolution`, `uTime`, `uTheme`, plus params. Parsing: `effect="glow rgb-split"`; per-effect params from attributes prefixed by effect name, e.g. `glow-strength="0.8"`.
- Scene: if `object.effects.length`, render the object into its own FBO (quad size), run chain ping-pong, composite into scene FBO; otherwise draw directly. Scene chain runs on the scene FBO at half resolution, then final blit to canvas. When `w` or `h` is 0 the scene skips the frame (Review Focus 4) and FBOs resize on next non-zero size.
- Effects: `glow` (`threshold` 0.5, `radius` 8, `strength` 0.8: bright-pass + separable blur done in two internal passes + add), `beam` (`angle`, `length`, `strength`: directional streak), `rgb-split` (`amount` px), `pixelate` (`size` px), `dither` (4×4 Bayer, `levels`), `scanlines` (`density`, `opacity`).

### Task 6: Interactions: pointer-follow, hover-lift, gravity

**Files:**
- Create: `src/interactions/{index.ts,pointer-follow.ts,hover-lift.ts,gravity.ts}`
- Modify: `src/core/scene.ts`, `src/core/object.ts`, `src/index.ts`

**Interfaces:**
- `type Interaction = { meta: { name: string; description: string; params: UniformDef[] }; setup?(scene: SdScene): void; frame(scene: SdScene, dt: number, pointer: {x,y,inside:boolean}): void }`. Writes into each `object.anim` (`offset`, `rotation` additive, `scale` multiplicative, `z`) and `object.state` target.
- Scene tracks pointer in scene-local px (`pointermove`, `pointerleave`), passes to interactions; also sets per-object `uPointer`.
- `pointer-follow`: spring (`stiffness` 0.08, `damping` 0.8) toward tilt of ±20° based on pointer offset from object center.
- `hover-lift`: object under pointer (rect hit test) → `scale` target 1.08 and `state` target 1; others fall back.
- `gravity`: center = first child with `gravity="center"` (Review Focus 3: extra centers are treated as `orbit`). Others: default `orbit`, or `fall`, `none`. Rest radius = distance from object's layout center to the center's layout center; orbit at angular speed `0.25 rad/s × gravity-strength` (scene attr, default 0.6) around the center, eased in; `fall` eases toward the center and stops at `gravity-gap` (object attr, default 24 px); `z = sin(angle)` for draw order and a ±6 % scale depth cue. Changing the center eases every object's offset to its new path over ~800 ms. Scene with no center: interaction is a no-op.
