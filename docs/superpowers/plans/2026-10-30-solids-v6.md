# solids v6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Shades become a fifth registry layer (glass, matte, cel, clay, metal) with a `shading` attribute, pages and a comparison page; every preview stage shows an fps badge.

**Architecture:** The prelude loses `sdGlass` and forward-declares `sdShade` and `sdEdge`; a shade is GLSL concatenated between the prelude and the object fragment, so the program cache holds one program per (object, shade). A `shades` registry mirrors `effects` (manifest, frag, params as `<shade>-<param>` attributes). The site generator emits shade pages, a comparison page, a catalogue row and a Shading select in every dock; a `.fps` badge component is rendered into every stage and fed by site.js.

**Tech Stack:** TypeScript + esbuild, WebGL2 GLSL, headless-Chrome check (`npm run build && npm run site && npm run check`, sandbox bypass).

**Spec:** `docs/superpowers/specs/2026-10-30-solids-v6-design.md`

## Global Constraints

- Zero dependencies; core bundle under 18 KB gzipped, full under 60 KB.
- No em dashes in copy or docs. Check page: no backticks or `${` in case code; `[0-9]` not `\d`.
- Objects stay shade-agnostic: no object `frag.glsl` changes except none; `map()` untouched.
- The light default shade is one constant, `LIGHT_SHADE = 'matte'`, in `src/core/registry.ts`.

## Review Focus

1. A pasted v1 to v5 page with no `shading` attribute anywhere renders exactly as before in dark (glass), and the light theme changes look only through the new default. Pinned by the pixel check "glass dark equals the pre-v6 orb" (compare against `shading="glass"` explicitly).
2. An object inside a scene with `shading="cel"` and its own `shading="auto"`: auto must mean the theme default, not "inherit". Spec order is object, then scene, then auto; an explicit `auto` on the object therefore wins over the scene. Pinned in Task 2's inheritance check.
3. Shade params set on the scene for a shade the object does not use are harmless; params for the active shade merge scene under object. Pinned in Task 2.
4. 60 programs: the hero compiles 12 on load as today (one shade); switching the dock's Shading select compiles 12 more in one frame. Acceptable hitch; the review judges it.
5. The fps badge on a paused or offscreen scene must not read `0 fps` forever on first paint: it shows the last value or a dash until the first frame. Pinned in Task 5's site check (badge text matches `[0-9]+ fps` on the visible stage).
