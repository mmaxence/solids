# solids v7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Land the correctness, performance, simplification and page findings of the three v7 audits, each pinned by a check, without structural rewrites.

**Architecture:** No new modules except `center()`/`radius()` on the object and `spring()` in math. Universe bodies move to a WeakMap; blur becomes an object field; scene buffers become lazy. Everything else is local edits.

**Tech Stack:** TypeScript + esbuild, GLSL, headless-Chrome check (`npm run check` now builds and generates the site first; sandbox bypass).

**Spec:** `docs/superpowers/specs/2026-10-30-solids-v7-design.md`

## Global Constraints

- Core under 18 KB gzipped, full under 60 KB. No em dashes. Check page: no backticks or `${`; `[0-9]` not `\d`.
- Pixel-identical unless the spec says otherwise; the march and cull changes are pinned byte-identical.

## Review Focus

1. Clamping at parse time changes what `getAttribute` round-trips through Copy code: the attribute keeps the author's value while the uniform is clamped. Acceptable; pinned by the clamp cases.
2. Lazy scene buffers: per-object effect chains still need the pool and a blit to the default framebuffer with the scissor set; pinned by the object-effect pixel case plus byte equality against the buffer path.
3. Starting scenes invisible: the lone-object path and `solidsBench` call `frame()` directly and must still draw; pinned by the lone case.
4. Bodies in a WeakMap: `generate()` must still seed deterministically (same signature for the same seed); pinned by the existing `same`/`other` case.
5. The reflection guard must not skip a legitimate uniform whose camelCase name is new; pinned by the walk over observed attributes.
