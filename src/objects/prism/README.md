# prism

A glass prism: a flat polygon pulled up into a column, tipped toward you so the top face shows. Three sides make a classic triangular prism, six a hexagonal nut, and a low height turns it into a tile.

- `sides` (3 to 8, default 6): number of side faces.
- `height` (0.3 to 1.2, default 0.8): height of the column.

```html
<sd-scene>
  <sd-prism color="color(display-p3 0.55 0.85 1)" sides="3" animation="idle"></sd-prism>
</sd-scene>
```
