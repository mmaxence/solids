# star

A glass star with beveled edges, like a cut ornament. The bevels catch the light from every side, so it works for ratings, rewards, and celebration moments.

- `points` (4 to 8, default 5): number of points.
- `depth` (0.1 to 0.5, default 0.26): thickness of the star.

```html
<sd-scene>
  <sd-star color="#ffd29b" animation="idle" state="active"></sd-star>
</sd-scene>
```
