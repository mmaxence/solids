# coil

A helix of glassy tube, like a spring standing on end. Spinning it makes the turns appear to climb.

- `turns` (1 to 6, default 3): number of windings.
- `thickness` (0.03 to 0.2, default 0.09): tube radius.
- `radius` (0.15 to 0.6, default 0.38): radius of the helix.

```html
<sd-scene>
  <sd-coil color="color(display-p3 0.5 1 0.85)" animation="spin" speed="0.5"></sd-coil>
</sd-scene>
```
