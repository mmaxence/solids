# disc

A glass coin with a beveled edge and a gently domed face, tipped back so both the face and the edge show. `spin` makes it flip like a tossed coin, which suits points, credits, and rewards.

- `thickness` (0.06 to 0.4, default 0.16): how thick the coin is.
- `bevel` (0 to 1, default 0.5): how much of the edge is chamfered.

```html
<sd-scene>
  <sd-disc color="color(display-p3 1 0.8 0.5)" animation="spin"></sd-disc>
</sd-scene>
```
