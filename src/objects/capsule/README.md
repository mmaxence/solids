# capsule

A rounded glass pill lying on a diagonal. It is the softest shape in the set and stays legible at small sizes, which makes it a good satellite around a larger center.

- `span` (0 to 0.9, default 0.7): length of the straight part. 0 makes a sphere.
- `radius` (0.12 to 0.4, default 0.27): how thick the pill is.

```html
<sd-scene>
  <sd-capsule color="#9bffe0" animation="float"></sd-capsule>
</sd-scene>
```
